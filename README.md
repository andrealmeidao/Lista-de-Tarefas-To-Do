# Lista-de-Tarefas-To-Do
Projeto simples de Lista de Tarefas desenvolvido para praticar HTML, CSS e JavaScript. A aplicação permite adicionar, marcar como concluída e remover tarefas, além de salvar os dados no navegador usando localStorage.
 Lista de Tarefas (To-Do List)

 Funcionalidades

* Adicionar novas tarefas
* Marcar tarefas como concluídas
* Remover tarefas da lista
* Salvar tarefas automaticamente no navegador
* Contador de tarefas
* Contador de tarefas concluídas
* Barra de progresso das tarefas

 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage (armazenamento no navegador)

 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de **praticar manipulação do DOM, eventos e armazenamento local no JavaScript**, além de reforçar conceitos de estrutura e organização de código.

 Como executar o projeto

1. Clone o repositório
2. Abra o arquivo index.html no navegador
ou acesse a versão online
**https://andrealmeidao.github.io/Lista-de-Tarefas-To-Do/**

 Aprendizados
Durante o desenvolvimento deste projeto foram praticados:

* Manipulação do DOM
* Eventos em JavaScript
* Armazenamento com localStorage
* Organização de funções
* Estrutura básica de aplicações web
